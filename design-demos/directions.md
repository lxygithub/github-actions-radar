# 六张方向卡 · GitHub 副业雷达 UI 重构

共同 spec 见 spec.md。三版共用 2026-11-11 那份真实数据（扫80/留8/Top1 floorplan 78分）。

---

## 候选 1 · 最佳设计师 A｜Massimo Vignelli / Unimark（瑞士国际主义信息设计）
- **借的是什么**：严格模块网格 + 1px 规则线分栏 + 只用两个字号层级制造秩序；把列表当成表格来排版而不是卡片堆。数据形状：分数是右对齐的等宽数字列。
- **不借的、自己长的**：不用它惯用的纯红纯蓝瑞士旗配色；颜色从 GitHub 夜间界面长——墨蓝底 + 单一电光蓝强调，分数用绿/琥珀作状态语义。
- **主角素材**：巨号日期与"80→8"漏斗数字作为版面锚点，项目列表是规则线切割的表格行。
- **骨架**：顶部窄条（标题/导航）→ 一屏高的统计行（80/72/8/68 四个大数用竖线分栏）→ 项目以表格行排列（序号·项目名·语言·分数·落地一句）→ 点开行的详情作为下方展开区。
- **胆量花在哪**：完全去掉卡片，整页靠规则线和留白分区，字号反差克制但网格极严谨。
- **form 来自内容的哪里**：雷达是"筛掉 72 留 8"的漏斗，版式本身就是一条从左到右收窄的漏斗。

## 候选 2 · 最佳设计师 B｜原研哉 / 无印（日式白画廊，轮盘 web-20 命中）
- **借的是什么**：错落网格 + 极大留白 + 细字小标 + 物品作为主角安静陈列；“每一件只说一句话”的克制。样张量得：主色占比 <5%，大片白底，格子不等宽错落。
- **不借的、自己长的**：不用它的米色陶土；用冷白底 + 墨黑字 + 一点雷达蓝，气质从"代码"而非"烘焙"来。
- **主角素材**：8 个项目像展品一样散落在错落网格里，每个只有项目名 + 一句"改哪一处" + 分数角标。
- **骨架**：左侧竖排大标题与一句定位 → 右侧错落网格陈列 8 项 → 大面积呼吸感。
- **胆量花在哪**：极致留白，一屏只放 3-4 项，靠滚动展开。
- **form 来自内容的哪里**："每天只留 8 个"的稀缺感，用留白把每个项目供起来。

## 候选 3 · 现实参照｜Bloomberg Businessweek（媒体级粗野主义，样张 web-01）
- **借的是什么**：120px+ 巨号 headline 直接压住 14px 小正文的极端字号反差 + 1px 规则线分栏 + 高信息密度刻意不留白。量得：标题字号是正文 8 倍，黑色面积 >40%。
- **不借的、自己长的**：不用它的超链接蓝 #0000EE 和信号橙红；用项目分数的高低自然生成"信号色"（高分配冷绿、临界配琥珀），颜色是数据的函数不是装饰。
- **主角素材**：巨号"8 / 80"作为头版数字，项目列表像报纸分栏。
- **骨架**：报头式导航 → 巨号数字 headline → 规则线切分的多栏项目 → 底部小字排掉的仓库。
- **胆量花在哪**：字号反差拉满，一根通栏红线。
- **form 来自内容的哪里**：这是"情报简报"，不是产品官网；每天一版，头版数字就是当天战果。

## 候选 4 · 现实参照｜Linear 暗色 Bento（样张 web-13）
- **借的是什么**：暗色低对比底 + 微妙发光边 + Bento 不等大格子 + 组件级信息密度。借一条：把不同重要度的信息放进不同大小的格子。
- **不借的、自己长的**：不走它的紫蓝渐变发光；用单色电光蓝描边，DeepInfer 等项目按分数分配格子大小。
- **主角素材**：Bento 格子阵列，Top1 占大格。
- **骨架**：顶栏 → 2×3 Bento 统计与 Top1 → 下方均匀项目格。
- **胆量花在哪**：Top1 独占大格。
- **form**：雷达评分体系天然有高低，Bento 格子大小映射分数。

## 候选 5 · 秒数轮盘 web-20｜原研哉白画廊
- 与候选 2 同源（都抽到原研哉白画廊），合并，不单独做。

## 候选 6 · 秒数轮盘 east-04｜上海装饰艺术月历
- **借的是什么**：双层细边框 + 几何扇形放射 + 装饰艺术竖排标题 + 三色克制（墨绿/赭金/砖红）。借一条：用边框层级把信息分成"外框/主体/角标"。
- **不借的、自己长的**：不用咖啡主题与民国字体；底色用深海蓝绿，金色只用于等级标识（S/A/B），红用于风险提示，三色都有语义。
- **主角素材**：项目卡作为"票券"，双层描边 + 角标等级。
- **骨架**：装饰性外框 → 竖排刊头 → 项目票券列表。
- **胆量花在哪**：整页做成立轴气质的复古版面（这是唯一一个"用力"的方向）。
- **form**："副业雷达"当作每日情报刊物。
