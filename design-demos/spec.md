# 设计 Spec · GitHub 副业雷达 UI 重构

## 项目是什么
一个每天自动运行的 GitHub 选品雷达：扫约 80 个仓库 → 硬过滤 + 六维打分 → 只留 8 个"能说清改哪一处 / 卖给谁 / 怎么交付"的项目。静态站，整页加密 + 单密码口令门。

## 受众与场景
- 中文独立开发者 / 想做副业的程序员，早上打开看"今天有什么能动手的"。
- 主要页面：① 日报页（8 张项目卡，每卡含打分拆解 + 项目简介 + 落地四问）② 归档页（最近 3 天 + 选品库检索）③ 设置页（滑块调筛选参数）。
- 观看距离：桌面为主，屏幕阅读；信息密度高，需要快速扫读。

## 核心信息（三版共用同一份真实数据）
- 2026-11-11 · 扫 80 / 排 72 / 留 8 / 均分 68
- Top1：haydenschmitty/floorplan · 78 分 · "用 Claude 读取代码库生成交互式架构图"
- 每项目：分数、grade、语言、许可证、stars、方向、简介、改哪一处/卖给谁/怎么交付/工时/风险
- 页面功能：上一份/下一份、历史归档、筛选设置、手动重跑、明暗主题切换

## 情感基调
不是消费级产品的活泼，也不是纯终端的冰冷。要"情报简报"的气质：可信、克制、有判断力，打开就知道这是认真筛过的东西。

## 输出格式（三版统一）
单文件 HTML，日报页主视图（1440 宽桌面），含真实 8 项目数据 + 顶部导航 + 统计摘要 + 筛选设置入口示意。可点击：主题切换、上一份/下一份示意。

## 已知约束
- 零外部依赖，字体用系统栈或 Google Fonts（演示版可用），图片非必需（数据是主角）
- 正文 ≥14px，标签 ≥12px，对比度 ≥4.5:1
- 现有设计系统（codebase lift）：深色 #0e1117 / 卡片 #171c26 / 线 #2a3242 / 字 #e8ecf4 / 强调 #7aa2ff / 系统字体栈 / 880px 宽
- 落地时须改 scripts/render.mjs 的 CSS + 结构，保持纯函数、无依赖、加密流程不变

## 图片需求
数据即主角（分数、数字、项目名），不需要外部图片；logo 沿用仓库现有 favicon.svg。不编造数据、logo 墙。
